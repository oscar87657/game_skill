# 2.5D 횡스크롤 메트로배니아 게임 디자인

## 한 문장 소개

3D 공간을 측면 시점으로 탐험하고 이동 능력을 획득해 기존 지역의 새로운 길을
여는 횡스크롤 액션 RPG.

## 방향성 참고

`ENDER MAGNOLIA: Bloom in the Mist`를 조작과 탐색 구조의 참고점으로 삼는다.

- 빠르고 명확한 좌우 이동과 점프
- 수평 진행 사이에 배치된 수직 탐색 동선
- 전투와 탐험에 함께 쓰이는 이동 능력
- 체크포인트와 지름길을 통한 부담 없는 백트래킹
- 전경, 플레이 레인과 배경을 분리한 깊이감

참고작의 캐릭터, 세계관, 맵 구조와 시각 표현은 복제하지 않는다. 프로젝트
고유의 설정과 3D 아트로 같은 장르의 조작 및 탐색 원칙만 검증한다.

## 첫 공개 목표

`v0.1.0`은 완성형 게임이 아니라 핵심 재미를 검증하는 20~30분 분량의 수직
슬라이스다.

- 연결된 구역: 3개
- 이동 능력: 3개
- 일반 적 유형: 3개
- 보스: 1개
- 체크포인트: 3~5개
- 주요 백트래킹 보상: 최소 3개

## 핵심 기둥

### 탐험

멀리서 보이는 장소와 닫힌 길이 호기심을 만들고, 짧은 순환 구조와 지름길이
현재 위치를 이해하도록 돕는다.

### 능력 해금

새 능력은 단순한 열쇠가 아니라 이동과 전투에서 모두 의미가 있어야 한다.

### 백트래킹

이미 방문한 공간으로 돌아갈 때 이동 방식, 적 배치 또는 접근 가능한 보상이
달라져야 한다.

### 간결한 전투

적의 수보다 패턴의 명확성을 우선한다. 이동 능력을 회피와 공격 기회 생성에
함께 활용한다.

## 핵심 플레이 루프

```text
새 구역 탐색
  → 잠긴 길과 위험 발견
  → 전투 및 체크포인트 확보
  → 이동 능력 획득
  → 새 길 개방
  → 이전 구역으로 복귀
  → 지름길과 선택 보상 발견
```

## 플레이어 기본 동작

- 좌우 달리기
- 점프
- 회피
- 기본 근거리 공격
- 상호작용

## 수직 슬라이스 능력

### 공중 대시

- 탐험: 긴 틈과 움직이는 발판 통과
- 전투: 공격 회피 후 빠른 거리 좁히기

### 2단 점프

- 탐험: 높은 발판과 세로형 지름길 접근
- 전투: 지상 공격 회피와 공중 공격 기회

### 벽 잡기

- 탐험: 금속 또는 지정 표면을 이용한 수직 이동
- 전투: 추격 회피와 유리한 위치 확보

능력 목록은 프로토타입 결과에 따라 바꿀 수 있지만, 수직 슬라이스에서는 세
개를 넘기지 않는다.

## 월드 구조 원칙

- 구역 세 개가 한 방향으로만 이어지지 않고 최소 한 개의 순환 경로를 가진다.
- 실제 이동은 X/Y 평면에 한정하고 Z축은 전경과 배경 연출에 사용한다.
- 카메라 경계와 방 단위 구도를 사용해 다음 목표를 읽기 쉽게 보여 준다.
- 다음 능력이 필요한 장소는 능력을 얻기 전에 한 번 보여 준다.
- 체크포인트에서 주요 목표와 지름길 중 하나 이상이 시야에 들어온다.
- 백트래킹 보상은 체력 강화, 선택 전투 또는 새로운 정보 중 하나를 제공한다.
- 구역 입구는 색, 형태, 조명으로 구분한다.

## 진행 데이터

반드시 저장할 상태:

- 획득한 능력 ID
- 마지막 체크포인트 ID
- 열린 영구 게이트 ID
- 처치한 보스 ID
- 획득한 영구 강화 ID
- 지도 방문 상태

일반 적의 생존 여부와 일시적인 물리 오브젝트는 기본적으로 저장하지 않는다.

## 기술 구조 초안

```text
AbilityDefinition (ScriptableObject)
        ↓
PlayerAbilityState
        ↓
AbilityGate / Movement / Combat
        ↓
SaveData
```

- `AbilityDefinition`: ID, 표시 이름, 아이콘과 설정값
- `PlayerAbilityState`: 현재 획득한 능력 집합
- `AbilityGate`: 요구 능력 ID만 참조
- `SaveData`: 능력 ID와 영구 월드 상태를 직렬화

## 아직 정하지 않은 항목

- 세계관과 주인공 설정
- 최종 아트 스타일
- 구역 이름과 테마
- 무기 종류
- 스토리 전달 방식
- 최종 플랫폼 확장

이 항목들은 이동 프로토타입이 재미있다는 판단 이후 확정한다.
