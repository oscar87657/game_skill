# 메트로배니아 학습을 위한 공간과 경험 질문

현재는 완성 게임의 콘텐츠를 확장하지 않는다. 구현 차이가 탐험 경험에 주는 영향을 작은 공간에서 검증한다.
Unity 실험은 기존 에셋을 활용할 수 있는 X/Y 이동의 2.5D를 기본 조건으로 유지한다.
2D 스프라이트나 다른 충돌 방식은 해당 비교가 필요할 때 독립 변수로 추가한다.

## 기능 실험과 장르 실험을 연결하기

| 기능에서 바꾼 것 | 공간에서 확인할 것 |
|---|---|
| 점프 높이·정점 시간·해제 제어 | 발판 간격, 낮은 천장, 도달 가능 경로와 실패 허용 |
| 대시·공중 행동 | 획득 전 보이는 길, 획득 후 재해석, 예상 밖 우회 |
| 공격 취소·전진량 | 좁은 발판 전투, 위험과 회피 선택 |
| 체크포인트·복구 범위 | 실패 부담, 적 재도전, 영구 진행의 이해 |
| 지름길·지도 정보 | 귀환 시간, 길 기억, 재방문 보상 |

## 작은 탐험 루프의 완료 조건

1. 처음 방문할 때 보이지만 아직 도달하지 못하는 목표가 있다.
2. 다른 경로에서 이동 능력 또는 이동 조건이 바뀐다.
3. 돌아와 이전 공간의 새 경로를 스스로 알아볼 수 있다.
4. 지름길로 반복 비용이 달라진다.
5. 숙련된 조작의 우회가 허용인지 오류인지 설계 의도를 설명한다.

현재 JumpLab은 발판·천장 비교 환경이며 이 탐험 루프는 아직 구현하지 않았다.

## 관찰 규칙

참고 게임은 질문마다 고른다. 하나의 작품을 전체 정답으로 두지 않는다.
화면에서 관찰한 입력·동선과 개발자 원문이 밝힌 구현을 구분한다.
다른 플레이어가 길을 발견하는지 확인하기 전에는 “가독성 검증 완료”라고 적지 않는다.
