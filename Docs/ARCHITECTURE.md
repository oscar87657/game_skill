# 아키텍처 규칙

## 의존 방향

```text
Input → Feature Controller → Domain/Data → Feedback/UI
                 ↓
              Physics
```

- 입력 액션은 게임 규칙을 직접 수행하지 않는다.
- 순수 계산은 `*Math` 클래스로 분리하고 EditMode 테스트를 우선한다.
- 런타임 컴포넌트는 하나의 상태·행동 책임만 가진다.
- 전투 대상은 구체적인 플레이어 클래스를 참조하지 않고 Health/Damage 계약을 사용한다.
- `CaptureStudio`는 Main의 런타임 계약을 재사용하되 촬영용 배치·이동
  단축키만 별도 계층에 둔다.
