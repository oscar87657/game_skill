## 3. 현재 구현 분석

| 코드 | 책임 | 장르 경험으로 이어지는 결과 |
|---|---|---|
| `FeatureController.cs` | Unity 입력·생명주기·물리 실행 | 실제 캐릭터 또는 월드 동작 |
| `FeatureMath.cs` | 상태 판단·수치 계산 | 경계에서도 예측 가능한 규칙 |
| `FeatureData.cs` | 설정·영구 ID | 콘텐츠와 런타임 상태의 분리 |

### 실행 흐름

```text
입력 또는 이벤트
  → 규칙 계산
  → 런타임 상태 변경
  → Unity 물리·월드 실행
  → VFX·SFX·UI 전달
```

현재 코드가 실제로 따르는 의존 방향과 상태 소유자를 적는다.

| 현재 방식 |  |  |  |  |  |
| 대안 A |  |  |  |  |  |
| 대안 B |  |  |  |  |  |

필요하면 저장 호환성, 디버깅 가능성, 플레이어 전달력 같은 기준을 추가한다.
