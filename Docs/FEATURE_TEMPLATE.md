## 3. 핵심 코드

| 코드 | 책임 | 이 코드로 구현한 동작 |
|---|---|---|
| `FeatureController.cs` | Unity 입력·생명주기·물리 실행 | 실제 캐릭터 또는 월드 동작 |
| `FeatureMath.cs` | 상태 판단·수치 계산 | 경계값에서도 일관된 결과 |
| `FeatureData.cs` | 변경 가능한 설정·영구 ID | 에셋과 런타임 상태 분리 |

파일 이름만 나열하지 말고, 해당 책임이 화면의 어느 동작으로 이어지는지 함께
쓴다.

## 4. 실행 흐름

```text
입력 또는 이벤트
  → 순수 규칙 계산
  → 상태 변경
  → Unity 물리·월드 실행
  → VFX·SFX·UI 피드백
```

기능의 실제 흐름에 맞게 바꾸고 의존 방향이 역전되지 않는 이유를 설명한다.
