# game_skill 프로젝트 계획서

## 1. 프로젝트 개요

### 목표

Unity 6.5로 2.5D 횡스크롤 메트로배니아의 핵심 구조를 직접 구현한다. 첫 공개
버전은 이동 능력을 해금하고 이전 지역으로 돌아가 새로운 길을 여는 경험이
담긴 20~30분 분량의 수직 슬라이스다.

세부 게임 규칙과 범위는 [게임 디자인 문서](GAME_DESIGN.md)를 기준으로 한다.

### 완료 상태

- 세 개 이상의 연결된 구역을 로딩 화면 없이 탐험할 수 있다.
- 세 가지 이동 능력이 탐험과 전투 양쪽에서 사용된다.
- 능력을 얻은 후 기존 지역에서 새로운 길과 보상을 발견할 수 있다.
- 체크포인트, 사망, 재시작 및 진행 저장이 안정적으로 동작한다.
- 일반 적 세 종류와 보스 한 종류가 등장한다.
- PC 빌드와 플레이 영상이 GitHub Release에 등록되어 있다.

## 2. 기술 기준

- Unity: `6000.5.5f1`
- Editor: macOS ARM64
- Render Pipeline: URP
- Input: Unity Input System
- Camera: 고정 측면 추적 카메라, 필요 시 Cinemachine 확장
- Navigation: X/Y 평면 기반 적 상태 머신
- Data: ScriptableObject
- Tests: Unity Test Framework
- Binary assets: Git LFS

Unity 버전과 핵심 패키지는 설치 후 고정한다. 버전 변경은 기능 작업과 분리된
커밋으로 수행한다.

## 3. 수직 슬라이스 범위

### 포함

- 걷기, 달리기, 점프, 대시
- 깊이축 고정 이동과 측면 추적 카메라
- 근거리 기본 공격과 능력 연계
- 세 가지 이동 능력
- 능력 보유 여부에 따른 탐험 게이트
- 서로 연결된 세 구역과 지름길
- 체크포인트, 회복, 사망 및 재시작
- 간단한 지도와 발견 상태
- 일반 적 세 종류와 보스 한 종류
- 진행 상황 세이브/로드

### 제외

- 대규모 오픈 월드
- 절차 생성 맵
- 멀티플레이
- 복잡한 제작 및 그리드 인벤토리
- 다수의 무기와 방대한 스킬 트리
- 모바일 및 콘솔 출시
- 풀 보이스와 장시간 컷신

새 아이디어는 Backlog에 기록하고 `v0.1.0` 이전 범위에는 추가하지 않는다.

## 4. 개발 원칙

1. 이동의 손맛과 카메라 안정성을 콘텐츠 양보다 먼저 검증한다.
2. 능력은 이동, 전투, 월드 게이트 중 최소 두 곳에서 사용한다.
3. 진행 조건은 Scene 이름이나 오브젝트 직접 참조 대신 능력 ID로 표현한다.
4. 능력 데이터와 적 설정에는 ScriptableObject를 활용한다.
5. Scene은 구역 단위로 분리하고 연결부를 명확히 관리한다.
6. 계산과 상태 전환 로직은 가능한 한 순수 C#로 분리해 테스트한다.
7. 기능 완료 시 코드, 테스트, 문서, 시각 자료를 함께 갱신한다.

## 7. Git 작업 방식

```text
main
feature/player-locomotion
feature/air-dash
feature/ability-gate
feature/checkpoint
feature/world-streaming
feature/boss-prototype
```

`main`은 실행 가능한 상태를 유지한다. 기능 브랜치는 한 가지 목적에 집중하고
완료 후 `main`에 병합한다.

| 접두어 | 용도 |
| --- | --- |
| `feat` | 새로운 기능 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변경 없는 구조 개선 |
| `test` | 테스트 추가 또는 변경 |
| `docs` | 문서 변경 |
| `chore` | 설정과 유지보수 |

## 8. 주요 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 범위가 계속 커짐 | 수직 슬라이스 수치를 고정하고 새 아이디어는 Backlog로 이동 |

| 백트래킹이 단순 반복이 됨 | 새 능력으로 지름길과 선택 보상을 동시에 제공 |

| 저장 데이터가 깨짐 | 버전 필드, 기본값, 왕복 테스트 추가 |
| Unity/패키지 버전 차이 | `6000.5.5f1`과 패키지 잠금 파일 커밋 |
| 바이너리 저장소 비대화 | FBX와 PNG를 Git LFS로 유지 |
