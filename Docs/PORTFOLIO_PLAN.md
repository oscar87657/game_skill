# 포트폴리오 운영 계획

이 저장소는 하나의 2.5D 메트로배니아를 완성하면서, 게임 기능을 작은 문제로
분해하고 구현 방식의 선택 근거를 기록하는 기술 포트폴리오다.

## 운영 원칙

- 하나의 `Main` 씬은 통합 플레이를 담당한다.
- 기능별 `Showcase` 씬은 해당 기능만 빠르게 재현하고 비교한다.
- 기능마다 코드, 테스트, 문서, 시연 자료를 한 묶음으로 남긴다.
- 구현 방식이 두 가지 이상이면 최소 하나의 대안을 문서로 비교한다.
- 최종 선택은 성능보다 현재 프로젝트의 요구사항과 유지보수성을 기준으로 설명한다.

## 기능 단위 완료 기준

1. 입력과 출력이 정의되어 있다.
2. 런타임 책임이 작은 컴포넌트로 분리되어 있다.
3. 정상·경계·실패 케이스 테스트가 있다.
4. Showcase에서 기능을 단독으로 재현할 수 있다.
5. README에 연결할 짧은 GIF 또는 스크린샷이 있다.
6. 선택한 구현 방식과 대안의 트레이드오프가 문서화되어 있다.

## 단계

### Phase 1 — 이동 포트폴리오

- 입력 추상화
- 가속 이동과 점프
- 코요테 타임·점프 버퍼
- 더블점프
- 지상·공중 대시
- 대시 속도 곡선
- 카메라 추적

### Phase 2 — 전투 포트폴리오

- 공격 상태와 쿨다운
- Hitbox·Hurtbox
- Health와 Damage 계약
- 피격·무적·사망
- 공중 공격과 캔슬
- 콤보 사이클
- 히트 스톱과 피드백

### Phase 3 — 월드 시스템

- 상호작용
- 체크포인트
- 능력 획득과 게이트
- 백트래킹 보상
- 저장·불러오기

### Phase 4 — AI와 공개 정리

- 적 상태 머신
- 보스 패턴
- 기능별 GIF·다이어그램
- 전체 아키텍처 문서
- GitHub Release와 플레이 영상

```text
v0.1-movement          이동 마일스톤
v0.2-combat            전투 마일스톤
```
