# 사망과 체크포인트 재시작

## 포트폴리오 목표

사망 이벤트 이후 여러 컴포넌트가 동시에 상태를 바꾸지 않도록 재시작 순서를
하나의 오케스트레이터에 모은다. 체크포인트가 없다면 최초 시작 위치를 사용해
어떤 시점의 사망도 복구 가능하게 만든다.

## 재시작 순서

```text
Health.Died
  → 이동 입력 잠금 및 속도 초기화
  → 공격 취소 및 전투 비활성화
  → 재시작 지점 결정
  → CharacterController를 끄고 위치 이동
  → 체력 완전 회복
  → 전투와 이동 조작 복귀
```

## 책임 분리

| 구성 요소 | 책임 |
|---|---|
| `DamageVolume` | Trigger 접촉을 데미지로 변환하고 대시 무적 확인 |
| `Health` | 데미지·사망·회복 상태와 이벤트 |
| `RespawnMath` | 체크포인트 또는 최초 위치 선택 |
| `PlayerRespawnController` | 사망 이후 실행 순서 조정 |
| `SideScrollerMotor` | 입력 잠금·이동 상태 초기화·안전한 순간 이동 |

`CharacterController`가 켜진 채로 `Transform.position`을 바꾸면 이전 충돌 해결의
영향을 받을 수 있다. 따라서 순간 이동 동안만 컨트롤러를 끄고, 이동 속도·대시
타이머·점프 횟수도 함께 초기화한다.

## 시연 방법

1. 시작 지점 오른쪽의 청록색 체크포인트를 통과한다.
2. 넓은 평지 중앙의 얇은 주황색 `RespawnHazard`에 일반 이동으로 접촉한다.
3. 잠시 조작이 멈춘 뒤 체크포인트 위치에서 체력이 복구되는지 확인한다.
4. 위험 지대 한 캐릭터 정도 앞에서 Shift 대시를 시작한다.
5. 위험 지대를 완전히 통과하고 대시 무적으로 사망하지 않는지 확인한다.
