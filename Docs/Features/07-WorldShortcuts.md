# 07. 구역 연결과 영구 지름길

> `WorldShortcutGate`의 표현과 `PlayerWorldState`의 Shortcut ID를 분리해,
> 샤프트 정상에서 연 통로가 재방문·저장 복원 뒤에도 유지되게 했다.

## 목표

백트래킹 샤프트를 오른 플레이어가 시작 홀 상단으로 돌아오는 순환 경로를
만든다. 지름길은 반대편에서 한 번 열면 사망과 재시작 뒤에도 현재 세션에서
열린 상태를 유지하며, 이후 세이브 데이터에는 Unity 오브젝트 참조가 아닌
영구 ID만 기록한다.

## Main 씬 동선

```text
시작 홀
  → 이동 실험실에서 벽 잡기 획득
  → 시작 홀 왼쪽 백트래킹 샤프트 등반
  → 정상 왼쪽 최대 체력 조각 획득
  → ShortcutActivator_ShaftTop 접촉
  → ShortcutGate_ShaftReturn 개방
  → Shortcut_ReturnBridge 횡단
  → 시작 홀로 낙하
```

`Shortcut_ShaftLanding`은 샤프트 정상 보상과 게이트 사이의 착지 공간이다.
게이트는 시작 홀 쪽에서 먼저 우회할 수 없는 높이에 있고, 활성 장치는 샤프트
쪽에서만 접근할 수 있다.

## 구현 후보 비교

| 방식 | 장점 | 단점 | 적합한 상황 |
|---|---|---|---|
| 게이트 GameObject 파괴 | 매우 간단함 | 저장 복원과 참조 유지가 어려움 | 저장이 없는 일회성 퍼즐 |
| 게이트 자체 `bool` 저장 | 오브젝트 단위 구현이 쉬움 | Scene 재생성과 분할에 강하게 결합 | 한 Scene의 작은 스테이지 |
| 플레이어 진행 ID + 이벤트 게이트 | 세이브·재시작·여러 Scene에서 재사용 | 영구 ID 관리가 필요 | 메트로배니아 지름길과 월드 상태 |

## 선택한 구조

```text
ShortcutUnlockVolume
          ↓
PlayerWorldState.TryUnlockShortcut(ID)
          ↓ 최초 해금 이벤트
WorldShortcutGate
          ↓
Collider·Renderer 비활성화
```

- `PlayerWorldState`: 열린 지름길 ID를 `HashSet`으로 소유
- `WorldShortcutGate`: 자신의 ID 상태를 구독해 물리 통로를 갱신
- `ShortcutUnlockVolume`: 올바른 플레이어 진입을 해금 요청으로 변환

게이트는 매 프레임 상태를 검사하지 않는다. 최초 해금 이벤트가 발생했을 때만
자신의 ID를 비교해 갱신한다. 세이브 복원처럼 상태가 먼저 준비된 경우에는
`Start`에서 다시 조회해 실행 순서 차이를 흡수한다.

## 수동 시연 방법

1. `Main` 씬을 Play하고 벽 잡기 능력까지 획득한다.
2. 시작점 왼쪽의 백트래킹 샤프트 정상으로 올라간다.
3. 정상 왼쪽의 세로형 조각에서 최대 체력 보상을 획득한다.
4. 정상 오른쪽의 주황색 구체에 접촉한다.
5. Console에서 `지름길 해금: shortcut_shaft_return`을 확인한다.
6. 주황색 게이트가 사라진 다리를 건너 시작 홀로 떨어진다.
7. 위험 지대에서 사망한 뒤에도 게이트가 열린 상태인지 확인한다.
