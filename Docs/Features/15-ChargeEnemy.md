# 15. 방향 잠금 돌진 적

> `ChargeEnemyDecisionMath`와 `ChargeEnemyController`로 선딜 순간의 방향
> 잠금과 벽·피격·발판 끝 중단을 분리해 예고를 보고 대응할 수 있는 돌진을
> 구현했다.

## 목표

M5의 세 번째 일반 적으로, 플레이어를 계속 따라오는 근거리 적이나 자리를
지키며 탄환을 쏘는 원거리 적과 다른 회피 판단을 요구한다. 노란 방향 예고를
읽고 점프로 넘거나, 돌진과 교차하는 순간 대시 무적을 사용하는 것이 핵심
경험이다.

## 현재 설정

| 항목 | 값 | 의도 |
|---|---:|---|
| 최초 탐지 거리 | `6.5m` | 높은 발판에 진입하면 예고를 볼 수 있음 |
| 추적 해제 거리 | `7.5m` | 탐지 경계에서 선딜이 떨리지 않음 |
| 허용 높이 차 | `1.7m` | 같은 발판의 플레이어만 공격 |
| 공격 선딜 | `0.55초` | 방향을 읽고 점프·대시할 시간 제공 |
| 돌진 속도 | `8.5m/s` | 일반 이동보다 빠른 순간 위험 |
| 최대 돌진 시간 | `0.55초` | 최대 약 `4.7m` 이동 |
| 공격 후딜 | `0.75초` | 회피 성공 후 반격할 창 제공 |
| 체력·데미지 | `4 / 1` | 공격 중단과 반격을 여러 번 시도 |

`ChargeEnemy_Rusher`는 폭 `12m`로 확장한 `High_Platform` 오른쪽 `x=22.2`에
배치했다. 청록색 상자는 대기 상태, 노란색 몸과 막대는 선딜, 빨간색은 실제
돌진, 짙은 청록색은 공격 후딜을 뜻한다.

## 상태 흐름

```text
대상 없음·6.5m 밖
        ↓
      Idle
        │ 같은 높이에서 탐지
        ▼
 AttackWindup 0.55초
        │ 종료 순간 목표의 좌우 방향 잠금
        ▼
      Charge ───── 접촉 1회 ────→ DamageRules
        │
        ├── 0.55초 만료
        ├── 벽 충돌
        └── 발판 끝 감지
                 ↓
       AttackRecovery 0.75초
                 └──────────────→ Idle

생존 상태 ── 피격 ─→ Hurt
모든 상태 ── 사망 ─→ Dead
플레이어 재시작 ──→ 최초 위치·체력·상태 복원
```

선딜 중에는 플레이어 방향을 표시하지만 돌진을 시작하는 순간
`chargeDirection`을 `-1` 또는 `1`로 고정한다. 따라서 돌진이 시작된 뒤
플레이어가 반대편으로 이동해도 적이 공중에서 급회전하지 않는다.

## 코드 파편화

| 구성 요소 | 책임 |
|---|---|
| `ChargeEnemyDecisionMath` | 탐지 히스테리시스, 방향 잠금, 접촉 범위 |
| `ChargeEnemyController` | 상태 시간, 중력, 돌진 이동, 발판 검사, 데미지 |
| `DamageRules` | 플레이어 생존과 대시 무적 공통 판정 |
| `Health` | 적 피격·사망과 플레이어 데미지 |
| `CharacterBodyCollisionPolicy` | 몸은 통과시키고 환경 충돌은 유지 |

```text
ChargeEnemyDecisionMath
          ↓
ChargeEnemyController ── CharacterController.Move
          │                         │
          │                         ├── 벽 CollisionFlags
          │                         └── 발판 Raycast
          └── DamageRules ─────────────→ Player Health
```

순수 판단 함수는 `Transform`, `Time`, `Physics`를 알지 않는다. 컨트롤러는 그
결과를 실제 프레임 이동과 시각 표현으로 변환한다. 이 경계를 통해 거리와
방향의 경계값은 EditMode에서 빠르게 검증하고, 실제 씬 연결은 PlayMode에서
별도로 검증한다.

## 돌진과 접촉 규칙

- 선딜 종료 순간 플레이어가 있는 좌우 방향을 잠근다.
- 돌진 중에는 플레이어 위치를 다시 추적하지 않는다.
- 플레이어와 적의 몸 Collider는 서로 밀지 않고 통과한다.
- 몸의 거리로 접촉을 판정하며 한 돌진에서 최대 한 번만 소비한다.
- 대시 무적 중 접촉해도 데미지를 주지 않으며 같은 돌진이 늦게 다시 때리지
  않는다.
- 플레이어 공격에 맞으면 선딜과 돌진이 모두 `Hurt`로 중단된다.
- 몸 앞 아래쪽 환경 Raycast가 바닥을 찾지 못하면 발판 끝에서 후딜로
  전환한다.
- 벽과 부딪히거나 최대 돌진 시간이 끝나도 후딜로 전환한다.

접촉을 물리 충돌 이벤트가 아니라 거리 규칙으로 처리하는 이유는 플레이어와
적의 몸 통과 정책을 유지하기 위해서다. 캐릭터끼리 밀지 않아도 공격 규칙은
독립적으로 동작한다.

## 구현 방식 비교

| 방식 | 장점 | 단점 | 현재 선택 |
|---|---|---|---|
| CharacterController + 거리 접촉 | 기존 지상 이동·환경 충돌 재사용, 몸 통과 정책과 호환 | 빠른 이동에서 접촉 범위를 조정해야 함 | 현재 프로토타입 |
| Rigidbody 동적 이동 | 충돌 반응과 밀치기가 자연스러움 | 플레이어·적 몸 통과와 제어 가능한 이동을 함께 맞추기 어려움 | 물리형 적에서 검토 |
| 애니메이션 Root Motion | 최종 애니메이션과 이동이 일치 | 그레이박스 단계에서 클립 의존성이 큼 | 실제 모델 적용 후 검토 |
| 위치 보간만 사용 | 구현이 단순하고 속도 곡선 제어가 쉬움 | 벽과 발판 충돌을 직접 검사해야 함 | 비물리 유령형 적에 적합 |

현재는 지상 발판과 벽을 존중하면서 기존 `CharacterController` 적과 비교하기
위해 첫 번째 방식을 사용한다.

## 수동 시연 방법

1. `Main` 씬을 Play하고 오른쪽 능력 구체와 계단을 지나 높은 발판으로 간다.
2. 발판 오른쪽의 청록색 `ChargeEnemy_Rusher`에게 접근한다.
3. 몸과 앞쪽 막대가 노란색이 되는 동안 적이 표시한 방향을 확인한다.
4. 막대가 빨간색으로 변하며 직선 돌진할 때 점프로 적을 넘는다.
5. 다음 돌진에서는 `Left Shift`로 적과 교차해 체력이 줄지 않는지 확인한다.
6. 발판 끝 가까이에서 적이 추락하지 않고 짙은 청록색 후딜로 전환하는지
   확인한다.
7. 선딜 또는 돌진 중 공격해 흰색 피격 상태로 행동이 중단되는지 확인한다.
8. 적을 처치한 뒤 플레이어도 사망해 적의 위치와 체력이 복원되는지 확인한다.

## 한계와 다음 단계

- 실제 돌진 애니메이션, 잔상, 충돌 VFX와 사운드가 필요하다.
- 현재 접촉 범위는 축 정렬 거리이므로 최종 모델의 Hurtbox 크기에 맞춰
  조정해야 한다.
- 좁은 발판에서는 최대 거리보다 발판 끝 검사가 먼저 돌진을 중단한다.
- 세 이동 능력과 일반 적에서 검증한 투사체 계약을 조합한 첫 보스는
  [Ability Trial Boss](16-AbilityTrialBoss.md)에 분리해 구현했다.
