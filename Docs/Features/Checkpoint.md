# 체크포인트와 회복

## 포트폴리오 목표

월드의 체크포인트 표현과 플레이어의 진행 상태를 분리한다. 체크포인트는
활성화·회복·재시작 위치 기록까지만 담당하고, 사망 흐름은 기록된 위치를 읽는다.

## 현재 구현

- `Checkpoint`: Trigger 진입과 활성 색상 피드백
- `PlayerCheckpointState`: 마지막 체크포인트 ID·재시작 좌표 소유
- 플레이어 최대 체력 5와 체크포인트 접촉 시 완전 회복
- 빈 ID와 NaN·무한대 재시작 좌표 거부
- `MaterialPropertyBlock` 기반 활성 색상 변경

## 책임 분리

| 구성 요소 | 소유하는 것 | 소유하지 않는 것 |
|---|---|---|
| `Health` | 현재·최대 체력과 데미지·회복 이벤트 | 체크포인트와 재시작 위치 |
| `PlayerCheckpointState` | 마지막 ID·위치와 회복 요청 | 월드 Trigger와 시각 효과 |
| `Checkpoint` | 접촉 감지와 활성 표시 | 플레이어 체력 값과 사망 처리 |

체크포인트가 플레이어를 직접 이동시키지 않는 이유는 사망 연출, 화면 전환,
CharacterController 초기화 순서를 다음 생존 흐름 컴포넌트에서 한 번에 관리하기
위해서다.

## 시연 방법

1. `Main` 씬을 실행한다.
2. 시작 지점 오른쪽의 청록색 기둥에 접촉한다.
3. Console의 `체크포인트 활성화: start_hall / 체력 완전 회복`을 확인한다.
4. Scene 뷰에서 체크포인트를 선택해 청록색 Gizmo로 재시작 위치를 확인한다.
