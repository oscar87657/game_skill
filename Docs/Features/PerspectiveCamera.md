# 정면 원근 2.5D 카메라

## 목표

플레이어 이동과 카메라 회전은 정면 2.5D 규칙을 유지하면서, 화면 중앙에서
멀어지는 3D 오브젝트의 옆면과 배경 깊이가 조금씩 보이게 한다. 조작 가독성을
해치지 않는 범위에서 완전한 평면 화면의 아쉬움을 줄이는 것이 목적이다.

## 투영 방식 비교

| 방식 | 장점 | 단점 | 적합한 연출 |
|---|---|---|---|
| Orthographic 정면 | 크기가 일정하고 2D 가독성이 가장 높음 | 옆면과 거리감이 거의 보이지 않음 | 순수 2D·타일 기반 게임 |
| Perspective 정면 | 가장자리 옆면, 전경·배경 크기 차이 표현 | FOV가 크면 왜곡과 멀미 가능 | 3D 모델을 쓰는 2.5D 게임 |
| Perspective 사선 회전 | 깊이와 옆면이 강하게 보임 | 이동축과 화면축이 어긋나 조작 판독이 어려움 | 디오라마·쿼터뷰 연출 |

이 프로젝트는 두 번째 방식을 선택했다. 카메라 회전은 `Quaternion.identity`,
플레이어는 `Z=0`을 유지하고 투영만 Perspective로 바꾼다.

## 기존 구도 보존

기존 Orthographic 카메라의 세로 반높이는 `5.2`였다. 원근 카메라에서도 같은
플레이 영역 높이를 보이기 위해 다음 식으로 거리를 계산한다.

```text
distance = verticalHalfExtent / tan(verticalFov / 2)
distance = 5.2 / tan(35° / 2)
distance ≈ 16.49
```

현재 설정은 다음과 같다.

| 항목 | 값 | 의도 |
|---|---:|---|
| Vertical FOV | `35°` | 가장자리 원근은 보이되 과도한 왜곡 억제 |
| 카메라 거리 | `16.49m` | 기존 세로 화면 범위 유지 |
| 카메라 회전 | `(0, 0, 0)` | 이동축과 화면축 일치 |
| 플레이어 깊이 | `Z=0` | 전투·충돌 규칙 유지 |
| 배경 깊이 | `Z=2.4` | 전경보다 조금 멀게 배치해 깊이 차이 표현 |

## 구조

```text
세로 반높이 5.2 + FOV 35°
              ↓
CameraPerspectiveMath
              ↓ 거리 16.49m
SideScrollerCamera.ConfigurePerspective
              ↓
정면 Perspective Camera + 기존 SmoothDamp 추적
```

- `CameraPerspectiveMath`: 구도 반높이·FOV·거리의 순수 변환
- `SideScrollerCamera`: 계산된 깊이를 추적 오프셋에 적용하고 Perspective 강제
- `PrototypeSceneBuilder`: Main 씬과 재생성 결과에 같은 기준값 적용

거리 숫자를 직접 입력하는 대신 구도 크기에서 계산하므로 FOV를 조절해도 기존에
보이던 플레이 영역을 기준으로 비교할 수 있다.

## 기대 효과

- 화면 중앙에서는 기존 횡스크롤과 거의 같은 정면 인상
- 좌우 가장자리의 두꺼운 발판·기둥에서 옆면 노출
- `Z=2.4` 배경과 `Z=0` 플레이 공간 사이의 미세한 크기 차이
- 카메라가 이동할 때 전경과 배경이 서로 다른 비율로 움직이는 원근감

실제 패럴랙스 레이어를 별도로 이동시키는 방식은 아직 사용하지 않는다. 현재
효과는 Perspective 투영과 기존 3D 깊이만으로 만든다.

## 수동 시연 방법

1. `Main` 씬을 Play하고 시작 홀 중앙에서 정면 가독성을 확인한다.
2. 좌우로 이동하며 화면 가장자리의 계단, 벽과 발판 옆면이 중앙보다 더
   보이는지 확인한다.
3. 이동 실험실의 긴 계단에서 배경과 전경 사이에 약한 깊이 차이가 보이는지
   확인한다.
4. 빠른 대시와 방향 전환 때 원근 왜곡이나 멀미가 느껴지지 않는지 확인한다.
5. Game 뷰를 16:9와 16:10으로 바꿔 플레이어 주변 시야가 과도하게 달라지지
   않는지 확인한다.

## 다음 조정 기준

- 입체감이 약하면 FOV를 조금 키우고 같은 식으로 카메라 거리를 다시 계산한다.
- 왜곡이 강하면 FOV를 줄여 더 멀리 배치한다.
- 배경 끝이 보이면 Additive 배경의 가로·세로 크기에 원근 여백을 추가한다.
- 최종 배경 아트 단계에서 전경·중경·후경 레이어를 서로 다른 Z에 배치한다.
