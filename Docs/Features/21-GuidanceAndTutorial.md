# 21. 진행 기반 길 찾기와 튜토리얼

> `GuidanceProgression`이 능력·구역·보상·보스 상태에서 다음 단계를 계산하고
> 하나의 `WorldGuidanceMarker`를 재사용해 진행과 어긋나지 않는 안내를 만든다.

## 목표

처음 플레이하는 사람이 별도 설명 없이 기본 조작을 익히고, 다음 능력과
백트래킹 목표를 찾은 뒤 보스전까지 도달하게 한다. 화면을 가리는 팝업 대신
상단의 짧은 목표·조작 힌트와 월드의 황금 비콘 하나를 사용한다.

## 범위

- 입력 학습: 이동, 점프, 대시, 기본 공격의 실제 성공 이벤트
- 진행 상태: 세 능력, 현재 구역, 샤프트 보상, 지름길, 보스 처치
- HUD 출력: 현재 목표와 상황별 조작 힌트
- 월드 출력: 다음 목적지로 이동하는 단일 부유 비콘
- 저장 연동: 불러온 능력·월드 상태를 읽어 완료한 안내 자동 건너뛰기

## 구현 후보 비교

| 방식 | 장점 | 단점 | 적합한 상황 |
|---|---|---|---|
| 고정 팝업 순서 | 구현과 번역이 단순함 | 플레이어 행동·세이브와 어긋나기 쉬움 | 선형 튜토리얼 |
| 모든 목적지에 표식 배치 | Scene에서 동선을 확인하기 쉬움 | 표식 수와 상태 조합이 늘어남 | 동시에 여러 퀘스트가 활성화되는 게임 |
| 진행 규칙 + 단일 재사용 비콘 | 현재 목표가 명확하고 Scene 비용이 작음 | 한 번에 한 목표만 강조함 | 현재 수직 슬라이스의 순차 진행 |

현재 구현은 세 번째 방식을 선택했다. 기본 조작은 입력 버튼을 눌렀는지가
아니라 `SideScrollerMotor`와 `PlayerCombat`이 실제로 승인한 `Jumped`,
`DashStarted`, `AttackStarted` 이벤트로 완료한다.

## 안내 흐름

```text
MOVE → JUMP → DASH → ATTACK
  ↓
DOUBLE JUMP → AIR DASH → WALL GRAB
  ↓
RETURN TO SHAFT → HEALTH FRAGMENT → SHORTCUT
  ↓
ABILITY TRIAL → BOSS → COMPLETE
```

- 능력을 하나라도 보유한 세이브는 반복적인 기본 조작 안내를 건너뛴다.
- 벽 잡기 획득 후에는 시작 홀 왼쪽 샤프트 입구를 가리킨다.
- 샤프트 구역 진입 뒤에는 같은 목표 안에서도 비콘이 정상의 체력 조각으로
  이동한다.
- 보상·지름길을 완료하면 오른쪽 보스방으로 목표가 바뀐다.
- 보스방 진입 뒤에는 입구가 아니라 보스 본체를 가리킨다.
- 보스 처치 상태가 복원되면 비콘을 숨기고 완료 문구를 표시한다.

## 코드 구조

```text
Motor / Combat ───── 성공한 조작 이벤트 ───┐
PlayerAbilityState ─ 능력 상태 ─────────────┤
PlayerWorldState ─── 구역·보상·보스 상태 ──┤
                                            ▼
                                  PlayerGuidanceController
                                            │
                           GuidanceProgression (순수 규칙)
                                      ┌─────┴─────┐
                                      ▼           ▼
                               Objective HUD  WorldGuidanceMarker
                                                  │
                                      GuidanceWaypoint 목록
```

- `GuidanceProgression`은 Unity 오브젝트를 참조하지 않고 같은 상태에 같은
  `GuidanceStage`와 문구·표식 ID를 반환한다.
- `PlayerGuidanceController`는 이벤트를 구독하고 상태를 읽지만 능력이나 월드
  진행을 직접 변경하지 않는다.
- `GuidanceWaypoint`는 표식 ID와 월드 좌표만 보관해 진행 규칙과 실제 레벨
  배치를 분리한다.
- `WorldGuidanceMarker`는 다이아몬드와 빔 Renderer 두 개를 가진 단일 View다.
  단계별 오브젝트를 만들지 않고 목표 좌표로 이동해 재사용한다.

## 수동 확인

1. 새 `Main` 실행에서 상단에 `MOVE RIGHT`, `[A / D] MOVE`가 표시되는지
   확인한다.
2. 이동, 점프, 대시, 공격을 하나씩 수행할 때 목표가 다음 조작으로 바뀌는지
   확인한다.
3. 기본 조작을 마치면 황금 비콘이 첫 능력 구체 위에 나타나는지 확인한다.
4. 세 능력을 순서대로 획득하면서 비콘과 힌트가 다음 목적지로 이동하는지
   확인한다.
5. 벽 잡기 획득 후 왼쪽 샤프트로 돌아가면 비콘이 입구에서 정상 보상으로
   전환되는지 확인한다.
6. 체력 조각과 지름길을 활성화한 뒤 비콘을 따라 보스방에 진입한다.
7. 보스를 처치하면 비콘이 사라지고 `VERTICAL SLICE COMPLETE`가 표시되는지
   확인한다.
8. 진행 세이브를 불러왔을 때 이미 완료한 능력·월드 안내가 건너뛰어지는지
   확인한다.

## 한계와 다음 단계

- 현재 키 문구는 키보드 기준이며 실제 게임패드 조작 확인 뒤 장치별 글리프를
  추가해야 한다.
- 단일 목표 구조이므로 이후 선택형 퀘스트가 생기면 중요도·거리 기반 목표
  선택 계층이 필요하다.
- 최종 아트 패스에서는 비콘의 색, 셰이더와 접근성 옵션을 함께 조정한다.
